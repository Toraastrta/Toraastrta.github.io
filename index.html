Merged fixes

  • WooCommercemerged#70900

    The Mini-Cart footer computed the cart subtotal on every render and wrote it to an Interactivity API store that nothing read. I removed the dead state and kept the now-unused protected method as deprecated, so extensions that subclass the block keep working.

  • React Routermerged#15776 · #15779

    Two fixes in one of the most used React libraries. Form encType and formEncType were compared case-sensitively, so encType="Multipart/Form-Data" fell back to URL encoding and file inputs were sent as just their file names. Memory history go() reported the requested delta even after clamping it at the start or end of the stack, so undoing a blocked navigation left the history on a different entry from the UI. Both were approved and merged by a maintainer.

  • PostHog (posthog-python)merged#1265

    Exception autocapture sent null instead of the truncated source line for any line longer than 1024 bytes. I traced it to a wrapper object that was never unwrapped, fixed it, and added a test that fails on the old code.

  • e2emerged#1837 · #1917

    The replay cache treated growing Japanese, Chinese and Korean tallies (42件, 42건이 검색되었습니다) as fixed page anchors, so recorded replays went stale. I extended the count pattern and checked the tests by deleting each part of the regex to confirm a test fails.

  • Zedmerged#66974

    Eleven settings documented a different default value from the one Zed actually uses. I corrected them against the real defaults. Approved and merged within about an hour.

In review

  • Supabase Storagein review#1722

    S3 requests for operations Storage does not implement, such as PutObjectTagging and DeleteObjectTagging, were routed to upload and delete. They overwrote or deleted objects and buckets while returning success. Reproduced with the AWS SDK against a real database; they now get 501.

  • WooCommercein review#71118

    The Variation Selector rendered a list with no list items, so screen readers announced an empty list (a critical axe-core error). I traced it to the change that introduced it and restored the missing role, with a unit test.

  • Code Snippetsin review#633

    In Safari, Save and Activate saved a snippet without activating it, because the editor read the pressed button from keyboard focus. I switched it to the submit event's button and kept Enter in the title field as a plain save, so it cannot deactivate a snippet by accident. Covered by end-to-end tests that fail before the fix.

  • Otter Blocks (Themeisle)in review#3187

    Centered text with the typing animation jumped sideways when the animation ended. I measured the text position in a running site, found two causes (the caret took up width, and a hidden copy of the last character was never cleared), and fixed both with unit tests that fail before the change.

  • LifterLMSin review#3510

    Post search results, such as the certificate template search, showed titles with raw HTML entities (&#8211; instead of a dash). An open bug since 2022. I decoded the titles the same way the rest of the package does and added a unit test that fails before the change.

  • Ghostin review#32937

    Comment counts did not render when the class option contained spaces.

  • flyctlin review#5479

How I work

  1. Reproduce the bug locally, in a test or a running app, before touching the code.
  2. Find the root cause, including the change that introduced it when there is one.
  3. Fix it in the smallest change that solves it, without breaking code that depends on the old behavior.
  4. Prove it: a test that fails before the fix and passes after, and a check in the running app.

I use AI tools (Claude Code) to move faster and say so in every pull request. I review every change and run the tests and checks myself.
