Selected fixes in other people's code

All merged by the projects' maintainers. Each one started from a reproduction, not a guess.

React Router merged #15776 · #15779

  • Problem: <Form encType="Multipart/Form-Data"> was submitted URL-encoded, so file inputs arrived as just their names, while the same form without JavaScript worked.
  • Reasoning: enctype is an enumerated HTML attribute whose keywords are case-insensitive. I confirmed what Chromium does on a plain HTML page, then fixed it in the one helper both the form and the submit button go through, leaving the typed useSubmit API alone.
  • Second fix: memory history go() clamped the index but reported the requested delta, and the router undoes a blocked navigation with that delta, so it overshot. I reported the distance actually moved and added regression tests for both ends of the stack.

Orca merged #44941

  • Problem: iOS 16.0–16.3 cannot parse regex lookbehind, and one literal anywhere in a loaded chunk stops the whole mobile web app. A recent change had added one back two days after the last ones were removed.
  • Reasoning: I rewrote it as an alternation that matches valid surrogate pairs first and lone halves second, which selects exactly the same text, and kept the replace-based approach instead of toWellFormed() because Android WebViews before Chromium 111 lack it. Merged the same day.

WooCommerce merged #70900

  • Problem: the Mini-Cart footer computed the cart subtotal on every render and wrote it to an Interactivity API store that nothing read.
  • Reasoning: I removed the dead state but kept the now-unused protected method as deprecated rather than deleting it, because extensions can subclass the block and call it.

PostHog, Zed, e2e merged #1265 · #66974 · #1837 · #1917

  • PostHog: exception autocapture sent null for source lines over 1024 bytes because a truncation wrapper object was never unwrapped. Added a test that fails on the old code.
  • Zed: eleven settings documented a different default from the real one; where sources disagreed, I settled it from the merged value and the release note. Merged within about an hour.
  • e2e: the replay cache treated growing Japanese, Chinese and Korean counts as fixed anchors. I checked the tests by deleting each part of the pattern and confirming one fails.

How I work

  1. Reproduce the problem first, in a test or a running app, before touching the code.
  2. Find the root cause, including the change that introduced it when there is one.
  3. Fix it in the smallest change that solves it, without breaking code that depends on the old behavior.
  4. Prove it: a test that fails before the fix and passes after, and a check in the running app.

I use AI coding tools (Claude Code) every day to move faster, and I say so in my pull requests. I review every change and run the checks myself.
